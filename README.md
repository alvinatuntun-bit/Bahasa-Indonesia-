# Evaluasi Bahasa Indonesia — 3 Tema Utama

Repositori ini berisi paket **Soal Evaluasi Mata Pelajaran Bahasa Indonesia** yang mencakup tiga kompetensi utama:

1. **Tema 1: Membaca** — Ide pokok, kalimat utama, teknik membaca (*skimming*, *scanning*, membaca nyaring), teks deskripsi, dan pemahaman kosakata.
2. **Tema 2: Memahami** — Pemahaman isi bacaan, tokoh & watak, amanat cerita, hubungan sebab-akibat, pertanyaan ADIKSIMBA (5W+1H), simpulan, fakta vs opini, dan makna ungkapan.
3. **Tema 3: Tanda Baca** — Penerapan kaidah EYD V untuk tanda titik (`.`), koma (`,`), tanya (`?`), seru (`!`), petik (`"..."`), titik dua (`:`), tanda hubung (`-`), serta penulisan tanggal dan judul.

## Cara Menggunakan

### 1. Versi Dokumen (Cetak / Lembar Kerja)
- Buka file `soal-evaluasi-bahasa-indonesia.md` untuk melihat seluruh naskah soal Pilihan Ganda (30 soal) dan Uraian (9 soal).
- Gunakan `kunci-jawaban-dan-pembahasan.md` sebagai panduan koreksi dan penilaian.

### 2. Versi Kuis Web Interaktif
- Buka file `index.html` langsung di peramban (Chrome, Edge, Firefox), **atau**
- Aktifkan **GitHub Pages** pada pengaturan repositori (`Settings -> Pages -> Branch: main`) agar kuis dapat diakses secara daring oleh siswa.
